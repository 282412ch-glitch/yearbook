## 记录与年册

浏览器 → 共享输入校验 → Fastify → DataStore 串行队列 → SQLite 事务及本地不可变媒体文件。网络模型等待不占用写队列。串行队列使快照、文件切换、图片上传等跨异步阶段操作不交错。

照片上传后校验内容、计算 SHA256。首次导入保留原文件，sharp 生成按 EXIF 方向规范化的阅读图及缩略图，exifr 提供可编辑的时间建议。保存记录时按顺序写入关联及图注。软删或移除某个关联不会删除共享原图。

发生日期是 `YYYY-MM-DD` 或 NULL，创建/修改/回顾时间另存 ISO 时间，不将发生日期转成 UTC。参数化中文包含查询按发生日期、人物、标签和关键词筛选。盲盒排除软删记录并保存近期展示历史。

年册树为“年册 → 章节 → 内容块”，内容块包括段落、原话、照片、记录卡片；独立关系表保留来源记录。同年可建多本年册，保存和采用版本都保留快照。AI 草稿与原记录、年册编辑稿分别保存。

## 未来信

草稿使用独立实体，允许不完整正文/日期；封存需要有效的今天或未来日期，并至少包含正文或照片。封存后不能更新内容或日期。每次查询按服务端本地 `YYYY-MM-DD` 比较到期情况，不依赖程序关闭时仍运行的定时器。

列表与首页摘要只返回信封元数据。未到期详情不返回正文、照片 ID、图注和 URL；到期 GET 不标已读，显式 POST read 才幂等记录首次阅读时间。所有信件均不进入普通记录检索或 Agent 素材范围。

媒体沿用原图哈希去重；独占未到期信的照片不能直接读取，也不能只凭 ID 重新关联到记录/年册/另一封草稿。已有可读记录、年册及保存版本等共享引用正常使用。完整文件重新导入并验证哈希后可以获得 30 分钟连接内授权；再次封存撤销授权，重启或备份恢复更换数据库连接后授权失效，不新增持久权限表。

封存是应用层的查看日期约束，不加密数据库或备份。日期依据本机时钟；本机文件仍由 Windows 用户与文件权限保护。

## 模型与 Agent

浏览器选择配置/授权素材 → 服务读取凭据 → 固定整理流程或受限工具循环 → 独立协议适配器 → 模型 → 结构及来源校验 → 保存阶段和新草稿 → 用户编辑/采用。

配置支持多套保存和独立能力状态。URL 保留路径前缀，不猜测额外 `/v1`；两个适配器分别处理请求、图片、工具往返、流式事件和用量。能力探测沿用配置的传输方式，各项能力仍独立验证。任务捕获配置版本，执行中配置变更会阻止后续请求发往变化后的服务。上游错误支持嵌套 HTTP 与顶层 SSE 结构，固定中文分类附带安全的 HTTP 状态、白名单错误码/参数名，不返回原始响应或 Key。

SSE 读取在协议完成标记后结束并取消 reader，不依赖网关关闭连接；Chat 等到 `[DONE]` 以保留 `finish_reason` 后的用量。Responses 对已声明的非完成状态拒绝返回部分稿；一次独立文本请求只发送所需字段，需要工具状态续接时才请求 encrypted reasoning。

Windows Credential Manager 保存实际密钥，数据库仅保存随机引用。系统不可用时用户可选择会话内存；从不自动降级到明文文件。浏览器只在提交设置时临时持有用户输入，服务返回值不包含 Key。

Agent 工具由本地代码执行，模型不能直接写数据库。工具参数严格校验；范围只含当前任务选定且仍存在、未软删的记录及照片。来源文字不能改变系统规则。每段、选图和章节引用都检查真实来源 ID、授权范围和图片归属；第一次章节仅允许用户标记的素材。

全年编册按月分批保存阶段，再汇总。分段和任务保存有幂等键；重新生成使用新任务和新草稿版本。来源不合法、照片未授权或将未标记的记录编入“第一次”章节时拒绝保存。文本事实仍需用户核对，来源 ID 校验本身不是语义真实性证明。

## 任务与生命周期

SQLite 保存 pending/running/completed/failed/cancelled、进度、错误、尝试次数、工具调用次数、用量及阶段。总时长/工具上限可配置，取消中止模型 HTTP 或打印进程；重试复用已完成阶段。用量只累加服务实际返回并校验通过的数字，无计数则未知。

每个执行带独立代次和 AbortController。取消/重试捕获当时的执行，防止迟到控制操作终止下一次尝试。暂停或恢复提升代次，旧网络结果不得写入新库；恢复开始前的慢 HTTP 请求在 body 处理后也会被拒绝。关闭顺序为 preClose 停 AI、模型请求及导出，onClose 再关闭数据库。

重启将未完成任务标为可重试失败，不自动发送新请求。AI 阶段保留；恢复备份后重新校验任务。导出运行集合按 DataStore 隔离，暂停等待旧执行收尾，文件名按尝试区分，失败清理临时文件。

## 导出

预览与导出由 `captureYearbookRenderSnapshot` 同时冻结已保存的年册、来源记录和媒体，再交给同一个 HTML/CSS 渲染器。显式空章节数组可保存空册；完全空白月份/封面占位省略，非空封面附记保留。照片模板用较宽版心、大幅照片与先图后文的记录卡片；文字模板使用宋体正文、较小图片与先文后图。长段落允许跨页，照片和短图注尽量同页，所有文字转义。

按内容所需 Unicode 范围从已安装的 Fontsource Noto Sans/Serif SC 包读取 WOFF2，作为 data URL 嵌入 HTML；图片也内嵌。ZIP 包含完整 index.html、OFL 许可证、清单及说明，不依赖 CDN。预览 iframe 读取同一服务端模板，仅该预览路由允许同源 frame-ancestors 和 data 字体，禁止脚本。

PDF 使用 Node 24 原生 WebSocket 与独立 Chromium 的 CDP 会话；仅监听随机本机调试端口，单独临时 profile、禁用扩展与联网，等待 `document.fonts.ready` 及全部图片 decode 后 `Page.printToPDF`，流式写文件并检查 PDF 完整结束。支持 `YEARBOOK_BROWSER` 指定路径。关闭通过 Browser.close，必要时只清理本次创建的浏览器 PID 及其子进程。找不到可用浏览器、资源损坏、超时或取消均有明确状态及重试，半成品不会标记完成。

## 备份与恢复

1. SQLite backup API 取得一致性快照。只在临时快照中清空模型凭据引用并重置能力，VACUUM 清理残留页；不修改原库。
2. 生成版本清单、必要媒体大小和 SHA256；不包含密钥、历史备份、临时导出、日志。
3. 恢复在独立 staging 目录验证白名单路径、大小、哈希、SQLite integrity/FK、精确表结构、迁移记录、AI 来源与媒体关系，以及信件状态、查看日期、封存/已读组合、照片顺序和关联。
4. 旧备份先按它的原始迁移版本校验，再在 staging 副本升级至当前版本。再次清空凭据引用和能力，避免恶意备份绑定本机已有密钥。
5. 暂停任务并保存恢复前 ZIP，写入恢复事务标记，将原库/媒体移到 rollback，再切换已验证文件。
6. 成功后清除标记；失败恢复原文件。程序中途退出，下次启动先保守回滚。旧版本备份和中文/空格新目录恢复均有独立测试。

每个自动化测试使用自己的临时 DataStore。Windows 启动器只通过随机实例令牌停止自己启动的服务，不按程序名批量终止进程。所有正式 data、运行日志、凭据与生成物排除在 Git 之外。
