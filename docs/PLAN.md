## 重要取舍

- SQLite 使用 `better-sqlite3`，迁移有版本与校验记录；单人本地服务绑定 127.0.0.1。
- 发生日期保存为 `YYYY-MM-DD` 或空值，创建/修改时间独立存 ISO 时间，不把日期转成 UTC。
- 图片按文件哈希去重，原图不可变；方向规范化的阅读图和缩略图为派生文件。
- 生产同源提供 UI/API。界面字体和图标随构建打包，不使用 CDN；导出专用字体尚待最终节点打包。
- AI、年册、未来信在对应节点完成前不显示虚假的成功结果。
