## 核心及接口测试验证的结果

- 本地日期、闰日与补记；中文关键词及人物/标签/年月组合筛选；一句话、纯图片和日期未定记录；输入失败不会保存半条资料。
- 真实 JPEG、EXIF 方向、缩略图、原图字节与哈希去重；外部原文件移动、记录关联删除和服务重启后，其他关联仍可读取。
- 软删恢复、人物/标签/回顾关联、盲盒零条/一条/多条及避免短期重复、用户主动标记的第一次。
- 同年多册、结构化章节/块/来源、版本保护、离线 HTML 任务；取消/重试幂等，维护暂停和关闭重开不会让旧导出继续写入。
- 两种协议分别验证前缀与完整地址、所选模型路由、文本/图片/工具/流式；工具结果实际往返、SSE 增量与结束、工具参数片段和可靠用量解析。文本成功不推断其他能力，假接受图片或工具不能误报支持。
- 无效地址、鉴权失败、模型不存在、超时、限流、暂时异常、能力缺失、截断和结构错误；错误不回显密钥。配置变更后拒绝旧任务请求，内部配置版本字段不发送给模型。
- 标题、整理、补问、月报、长中文分批与全年分月任务；主动授权照片、缺少能力降级、逐段来源、第一次限制、草稿版本保护、整册采用前保留手动稿。
- Agent 工具不能扩大范围、读取任意照片或执行终端；先检索再生成，保存幂等。取消、超时、工具上限、重试交叠和真实数据库关闭重开均保留正确任务状态和已完成阶段。
- 用量只保存服务实际返回且格式可靠的数字；截断/失败已有用量仍累计，没有则未知，不估算费用。
- 备份含一致性快照和必要媒体；哈希、结构、SQLite integrity/FK、AI 来源/媒体关联均校验。损坏或篡改备份被拒绝，原资料保留；恢复中断下次启动回滚。
- 迁移 1/2 的旧备份在原结构验证后升级至 4，独立中文/空格新目录恢复后记录、照片、年册和关联保持完整。凭据引用与能力在备份/恢复副本中清空，伪造引用不能借用本机已有 Key。
- 恢复期间迟到的 JSON 请求与恢复文件上传被拒绝，避免旧页面请求写入已更换的资料库。服务实例令牌与 PID 不匹配时不能停止其他进程。

## 实际浏览器流程

通过 `scripts/e2e.mjs` 和 `scripts/e2e-flows.mjs` 在隔离生产服务上执行：

1. UI 新建记录，批量导入横向/竖向两张照片；停止并重新启动后搜索、打开、软删和恢复。
2. 不配置模型，UI 手动编册，保存长中文、来源、封面、两张照片并预览；下载当前保存内容的 HTML ZIP。
3. 解压并打开真实 `file://` HTML，在浏览器离线状态验证完整中文、图片加载和横竖比例，随后恢复联网。
4. UI 保存 Responses 和 Chat Completions 配置，分别验证四项能力、获取模型列表、切换启用配置。
5. 标题生成保留原文快照；采用只预填记录编辑器，明确点击保存后才修改记录；主动生成两个补充问题。
6. 月报生成、手动编辑、窄窗口检查；重新生成后旧手动稿保留，采用章节追加到原年册。
7. Chat Agent 通过本地受限工具检索和生成，来源只指向选定素材；全年按月生成草稿，采用后能恢复采用前的手工版本。
8. 无工具模型明确降级；取消能力测试；取消任务后更改配置并重试，只有一份最终草稿。
9. UI 创建、下载并恢复备份；恢复后能力显示为尚未验证，需重新填写密钥。再次重启后保留 **2 条记录、2 张关联照片、1 本年册、8 份 AI 草稿**。
