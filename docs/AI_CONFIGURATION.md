# 模型 API 配置与 AI 助理（75% 节点）

本节点已经实现模型配置和 AI 工作流，协议与流程由本机确定性模拟服务覆盖。2026-09-12 已实测 AnyRouter：模型列表包含所填模型，但生成请求仍返回 `invalid codex request`，**真实生成尚未验证成功**。模拟服务不进行真实推理，不能保证任意服务的兼容性或生成质量。API Key 只在应用设置页填写，不需要发到对话中。详见 [模型配置诊断](MODEL_TROUBLESHOOTING.md)。

## 保存一套配置

打开“设置与备份 → 模型与 AI 助理 → 添加模型配置”，填写名称、协议、Base URL、精确模型名、请求超时和输出长度。支持保存多套配置、编辑、删除、切换；新任务使用选定配置。已有任务的请求不会因切换默认配置改发到其他服务。任务执行期间修改它使用的地址、模型或密钥，会拒绝后续请求；检查配置后可以重试，已完成阶段保留。

自定义地址需要兼容 **Responses** 或 **Chat Completions** 中所选的协议，不支持自动转换任意厂商原生协议。模型名可以完全手填。“获取已保存配置的模型列表”调用该地址的 `/models`；列表失败不影响保存或手填。

| 填入 Base URL | 选择协议 | 最终请求地址 |
|---|---|---|
| `https://api.openai.com/v1` | Responses | `https://api.openai.com/v1/responses` |
| `http://localhost:1234/v1/chat/completions` | Chat Completions | `http://localhost:1234/v1/chat/completions` |
| `http://localhost:1234/gateway/api` | Responses | `http://localhost:1234/gateway/api/responses` |
| `http://localhost:1234/responses` | Responses | `http://localhost:1234/responses` |

按服务说明填写 `/v1` 或其他前缀；程序不擅自增加 `/v1`。完整接口地址会去掉末尾接口名，再按所选协议生成最终地址，设置页实时预览。禁止 URL 中包含账号密码、查询参数、锚点或重复接口路径。HTTP/HTTPS 和 localhost 均可使用。

每次请求超时可设 1–600 秒，输出上限可设 64–131072 token；实际有效范围由服务和模型决定。本应用不计算价格。

## 密钥保存

- **Windows 系统凭据**：通过 Windows Credential Manager 保存。SQLite 只有随机引用；密钥不写普通配置文件、日志、备份、导出或前端资源。系统调用使用隐藏 PowerShell 进程，密钥经标准输入传递，不拼入命令行。
- **仅本次会话**：只保存在当前本地服务进程内存，关闭服务后失效。系统凭据不可用时可明确选择此模式。
- **不使用密钥**：用于无需 Key 的本机或兼容服务。

编辑时密码输入框不回填，留空可保留已有密钥，显式勾选“清除已有密钥”才清除；保存后清空输入框，不将 Key 写入浏览器 localStorage。删除配置同时清理其凭据。模型错误只返回中文分类说明，不回显上游响应或鉴权信息。

**备份不携带密钥，也不携带可复用的凭据引用。** 恢复后保留模型地址和名称，但需重新填写 Key，并重新验证能力。这样从别处导入的备份不能借用此电脑已有凭据。恢复前原库和系统凭据不会因为创建备份而被清空。

## 四项能力分别验证

| 能力 | 实际探测 | 成功不代表 |
|---|---|---|
| 文本生成 | 收到可解析的非空文字 | 支持图片、工具或流式 |
| 图片理解 | 随机颜色 PNG，只从图片获得颜色答案 | 任意照片理解准确 |
| 工具调用 | 模型返回合法参数，本地返回随机 receipt，模型正确回传 | 模型可以任意执行操作 |
| 流式输出 | SSE 文字增量及协议结束事件 | 仅 HTTP 200 就是成功 |

每项独立保存“尚未验证 / 已验证 / 未支持 / 验证失败”、原因和时间。各项验证均沿用已保存的流式设置；流式开启后，文本、图片、工具探测同样发送流式请求，但成功不会自动验证流式能力，仍须单独检查文字增量和完整结束事件。流式需先启用并保存，才能单独测试。可以取消验证，已有能力结果保留。地址、协议、模型、密钥、流式、超时或输出上限改变后重新验证；仅改配置名称保留结果。

错误区分无效地址、鉴权失败、模型不存在或无权限、网络连接失败、超时、限流、服务异常、参数拒绝、要求流式、网关 Codex 校验、图片/工具/流式不支持、结构异常、拒绝及输出截断。已识别错误显示 HTTP 状态和白名单错误码/参数名，不回显原始上游正文。没有收到协议的完整结束事件不会保存为成功结果；收到完整结束事件后即结束读取，不等待网关关闭连接。已取消或仍执行中的部分响应不能保存为成功稿。

## 使用 AI

- 记录详情：建议标题、整理文字、主动生成一到两个补充问题。生成不改原记录；标题或整理稿先预填编辑页，用户保存后才修改记录。
- 月末小报：选择月份 → 选择允许使用的记录 → 生成独立草稿。包含值得记住的事、现有照片及可编辑回顾，每段与照片都有来源。
- 年册编辑：生成全年草稿或用一句话整理章节。全年任务先按月分批保存阶段，再汇总成可编辑年册。
- 编册助理：在选择范围内检索、读取、编写草稿。可修改整理要求、照片授权与任务上限。素材中的文字只作为资料，不授予额外权限。

仅文字模型可以完成整理。没有验证图片能力时使用用户图注；发送图片需用户在“照片与执行范围”主动勾选，单次请求最多 6 张缩略图。没有验证工具调用时准确显示“程序筛选素材后生成”；即使已验证，运行时服务拒绝工具、图片或流式，也会降级并在任务和草稿中记录原因。

Agent 仅有 `search_records`、`get_records`、`get_selected_media`、`create_summary_draft`、`create_yearbook_draft`。参数由 Zod 严格校验，读写由本地程序执行，只能使用本次允许的记录和照片。没有终端、任意文件、跨资料库或未来信访问工具。“生活第一次”章节只能引用用户主动标记的记录。

草稿保留生成时的原文快照。重新生成创建新草稿，已有手动稿、原记录及历史版本保留。采用章节会追加；采用整册前保存当前年册版本，之后可在年册编辑页恢复。来源约束校验 ID 和授权范围，用户仍需核对文字是否符合实际经历。

## 任务与协议细节

任务在 SQLite 中保存待执行、执行中、完成、失败、已取消状态，支持进度、阶段文本、错误、取消、继续/重试。最长 30 分钟、最多 40 次工具调用，界面可缩小限制。重启后未完成任务标为需要重试，已完成阶段保留；不会自动重新向模型发送生活素材。幂等键、阶段复用和执行代次防止重复保存或取消后的迟到结果写回。

服务返回可信用量时记录实际输入/输出/总 token；包含已返回用量的截断或失败响应也保留计数。没有可靠用量时显示未知，不估算费用。

两个独立适配器分别构造和解析协议：

| 项目 | Responses | Chat Completions |
|---|---|---|
| 输入与输出 | `instructions/input`、`output` items | `messages`、`choices` |
| 工具定义 | 扁平 function 字段 | 嵌套 `function` 对象 |
| 工具结果 | `call_id/function_call_output` | `tool_call_id`、tool message |
| 图片 | `input_image` | `image_url` |
| 输出长度 | `max_output_tokens` | `max_completion_tokens` |
| 流式结束 | `response.completed` | `finish_reason` 和 `[DONE]` |

两种协议均显式 `store:false`。Responses 工具往返保留所需 reasoning output items 和 encrypted state；不会把 Chat 格式套到 Responses 上。模型请求、SSE 均有响应大小限制；不跟随重定向转发密钥。

## 本机模拟验证

`npm test` 中的模型测试会自动启动仅监听 127.0.0.1 的 HTTP 模拟服务，不读取真实 Key；`npm run test:e2e` 也使用独立模拟服务及临时资料。测试模块位于 `tests/mock-model.ts`，不会被生产构建自动启用。需要单独调试时：

```powershell
node --import tsx tests/mock-model.ts
```

它输出实际的本机 URL；`mock-all` 是正常模型，`no-tools`、`no-vision`、`no-stream`、`unauthorized`、`absent`、`limited`、`unavailable`、`timeout`、`malformed` 可检查降级或失败提示。所有模拟结果都应视为测试资料，不能作为真实服务验证记录。
